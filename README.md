# Smart Waste Management System — R26-IT-126

Academic information website for the SLIIT final-year research project **Smart Waste Management System** (Group R26-IT-126, Faculty of Computing, SLIIT).

**Live site:** https://ashenmayuranga.github.io/r26-it-126-website/

## About the project
An IoT and machine-learning framework for municipal solid waste management, made up of four integrated components:

| Component | Member |
|---|---|
| IoT-Based Environmental Sensing Smart Bin | Hemsara K.D.S. (IT22548528) |
| Smart Fill-Level & Occupancy Monitoring | Gamaariya C.C. (IT22202772) |
| ML-Based Waste Prediction & Revenue Hub | Jayawardhane K.G.M.S. (IT22213358) — Group Leader |
| Mobile App for Real-Time Bin Detection, Adaptive Route Optimization & Resident-Driven Coordination | Wijesiri A.M. (IT22088482) |

**Supervisor:** Mr. Uditha Dharmakeerthi  
**Co-Supervisor:** Mr. Kanishka Prajeewa Yapa

## What the website contains
Home, Project Scope (literature review, research gap, problem, objectives, methodology, technologies, architecture), Results & Findings, Field Visit, Milestones, Documents, Presentations, About Us and Contact Us.

## Technology
Static website built with HTML, CSS and JavaScript only (no server or database), hosted on GitHub Pages.

```
index.html      page content
style.css       styles
script.js       navigation, search, photo viewer, contact form
docs/           proposals, theses, checklists, presentation slides (PDF)
images/         team and field-visit photos
```
